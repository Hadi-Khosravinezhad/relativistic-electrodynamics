# Computational Relativistic Electrodynamics

A collection of numerical simulations, physical thought experiments, and analytical models exploring classical and relativistic electrodynamics across reference frames.

All implementations are developed in Python / Jupyter Notebooks, designed to run seamlessly in local environments, Kaggle, and Google Colab.

---

## 📚 Projects & Simulations

- [x] [**01: Motional Electric Field in Moving Frames**](01-motional-electric-field/)
  - Demonstration of induced electric fields observed from a moving frame in a static magnetic field (first order in $v/c$) using test-charge force consistency.
