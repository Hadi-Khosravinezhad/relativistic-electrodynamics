## 📌 Overview

This repository is dedicated to the pedagogical exploration and computational simulation of **Relativistic Electrodynamics**. It bridges classical Maxwellian electrodynamics and Einstein's special relativity through:
- Manifestly covariant tensor formulation ($F^{\mu\nu}$).
- Exact and non-relativistic Lorentz transformations of $\mathbf{E}$ and $\mathbf{B}$ fields.
- Dynamic phase-space and trajectory simulations of relativistic charged particles.
